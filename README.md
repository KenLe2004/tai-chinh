# Tài chính

App dashboard chi tiêu cá nhân (PWA). Trang này chỉ chứa giao diện; số liệu lấy từ Apps Script, khoản thu chi thêm bằng nút + cũng gửi về Apps Script, cả hai chỉ chạy khi có mã truy cập riêng, mã nằm trên thiết bị của chủ app, không nằm trong repo này.

Mở https://kenle2004.github.io/tai-chinh/ bằng Chrome, nhập mã một lần, rồi bấm "Cài app" để cài lên điện thoại hoặc máy tính.

# Tài chính

Vỏ app (PWA) để cài dashboard tài chính cá nhân lên điện thoại. Trang này chỉ chứa logo, khai báo app và lệnh mở dashboard Apps Script. Không có dữ liệu tài chính nào ở đây; dashboard chỉ chủ tài khoản Google đăng nhập mới xem được.

Mở link bằng Chrome trên Android => bấm "Cài đặt ứng dụng". Trang đứng yên ở đây để Chrome cho cài; app đã cài sẽ tự chuyển sang dashboard.
